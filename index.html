PROJECT 01Unity / C#

NyoiBox

Spriteの四隅を使った座標判定に取り組んだ作品。衝突判定を自分で組み立てることで、ゲーム内のオブジェクト判定を制御しています。

2DOverlapPointTilemap

IMPLEMENTATION

  • SpriteのBoundsから四隅のワールド座標を取得
  • 各点にOverlapPoint / Tile判定を実行
  • 条件に応じたヒット判定とオブジェクト削除

PROJECT 04Unity / C#

棒橋パズルゲーム

長押しで棒の長さを調整し、離すと棒が倒れる2Dゲーム。入力タイミングと物理挙動が結果に直結するよう設計しました。

2D PhysicsInput SystemUI

IMPLEMENTATION

  • 押している間に棒を伸縮し、離した長さを確定
  • Rigidbody2Dによる棒の転倒・落下挙動
  • 使用可能な棒の長さをゲージで表示
